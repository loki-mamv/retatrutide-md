# retatrutide.md

Evidence-based guide to **retatrutide** (LY3437943), Eli Lilly's first-in-class **triple agonist** targeting GLP-1, GIP, and glucagon receptors.

🔗 **Live site:** [retatrutide.md](https://retatrutide.md)

## What's Covered

- **What is retatrutide?** — First triple agonist (GLP-1 + GIP + glucagon)
- **Mechanism of action** — How glucagon receptor activation adds thermogenesis and fat burning
- **Phase 3 trial results** — TRIUMPH-3 (Dec 2025): avg 71.2 lbs weight loss
- **Comparison table** — Retatrutide vs Ozempic vs Mounjaro vs Zepbound
- **Side effects** — GI profile similar to other GLP-1 medications
- **Timeline** — 7+ Phase 3 trials completing 2026, FDA approval expected late 2026/2027
- **FAQ** — Common questions about availability, cost, eligibility
- **AI Q&A widget** — Ask questions, get answers from clinical trial data
